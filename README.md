# 비트드롭

노래를 넣으면 박자를 분석해서 리듬게임으로 만들어 주는 휴대폰용 웹 게임입니다.

플레이: https://dbehd0523-debug.github.io/-/

## 노래 넣는 방법

| 방법 | 노트 |
|---|---|
| 노래·동영상 파일 고르기 | 소리를 직접 분석해서 만듭니다 |
| 오디오 파일 링크 | 소리를 직접 분석해서 만듭니다 (외부 접근을 허용하는 사이트만) |
| 유튜브 링크, 미리 분석해 둔 곡 | 소리에 맞는 노트가 나옵니다 |
| 유튜브 링크, 분석 안 된 곡 | 박자를 두드려서 잡은 빠르기로 만듭니다 |

한 번 넣은 노래는 그 기기의 브라우저에 저장됩니다.

## 유튜브 곡을 미리 분석하기

브라우저는 유튜브 영상의 소리를 읽을 수 없어서, 소리에 맞는 노트를 내려면 곡을 미리 분석해 둬야 합니다.
`tools/yt-chart.mjs` 가 음원을 내려받아 분석하고 `charts/<영상 ID>.json` 을 만듭니다.
음원 파일은 분석 후 지우고, 분석 결과(소리가 나는 시각 목록)만 남깁니다.

유튜브에서 음원을 내려받는 것은 유튜브 이용약관에 어긋납니다. 사용 여부는 본인이 판단해 주세요.

### 집 컴퓨터에서 실행 (권장)

Node.js 18 이상, [yt-dlp](https://github.com/yt-dlp/yt-dlp), ffmpeg 이 필요합니다.

```bash
node tools/yt-chart.mjs "https://youtu.be/영상ID"
```

만들어진 `charts/영상ID.json` 을 이 저장소에 올리면, 게임에서 그 유튜브 링크를 넣었을 때 분석된 노트가 나옵니다.

이미 가지고 있는 파일로 분석할 수도 있습니다.

```bash
node tools/yt-chart.mjs 노래.mp3 --id 영상ID --title "곡 이름"
```

### 깃허브에서 실행

저장소의 Actions 탭 → `유튜브 노래 분석` → `Run workflow` 에 링크를 넣으면 같은 작업을 깃허브가 대신 합니다.
다만 유튜브가 서버에서 오는 접속을 자주 막아서("Sign in to confirm you're not a bot") 실패할 수 있습니다.
